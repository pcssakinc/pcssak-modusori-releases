# Contribution and issue conduct / 참여·이슈 작성 기준

This is the official binary-distribution, documentation, and issue-tracking repository, not the
private application source repository. Source-code pull requests and requests for proprietary
source access are not accepted here.

이곳은 공식 설치 파일 배포·문서·문제 제보 저장소이며 비공개 애플리케이션 소스 저장소가
아닙니다. 소스 코드 Pull Request나 독점 소스 공개 요청은 이곳에서 받지 않습니다.

Before opening an issue:

1. Use the newest fixed official release and verify its SHA-256.
2. Read the release notes, system requirements, known limitations, support, and security policy.
3. Search existing issues.
4. Reproduce the behavior yourself with non-sensitive data.
5. Submit one defect or one recurring user need per issue using the provided form.

이슈 작성 전 최신 공식 고정 릴리스와 SHA-256을 확인하고, 릴리스 노트·시스템 요구사항·
알려진 제한·지원·보안 정책을 읽고, 기존 이슈를 검색하고, 비민감 자료로 직접 재현한 뒤,
이슈 하나에 결함 또는 반복되는 사용자 요구 하나만 양식에 맞춰 제출하십시오.

AI-assisted reports are welcome only when the reporter has personally verified every claim,
command, screenshot, and attachment. Do not submit generated issue spam, speculative vulnerability
claims, benchmark claims without data and method, or text copied from another product.

AI 도움으로 작성한 제보는 제출자가 모든 주장·명령·화면·첨부를 직접 확인한 경우에만
허용합니다. 자동 생성 이슈 도배, 검증하지 않은 취약점 주장, 자료·방법 없는 성능 주장,
다른 제품에서 복사한 내용을 올리지 마십시오.

Be respectful. Do not post personal or confidential information, original recordings, full
transcripts, customer data, credentials, licence keys, exploits, or files you do not have the
right to share. Follow [private security reporting](SECURITY.md) for vulnerabilities.

서로 존중하십시오. 개인정보·기밀정보·원본 녹음·전체 전사·고객 자료·인증정보·라이선스 키·
공격 코드·공유 권한 없는 파일을 공개하지 말고 취약점은 [비공개 보안 제보](SECURITY.md)를
사용하십시오.

Maintainers may edit, label, close, lock, hide, or remove material that is unsafe, duplicated,
unreproducible, misleading, unlawful, abusive, or outside this repository's scope. Participation
does not create an implementation, schedule, payment, support, or confidentiality commitment.

관리자는 위험·중복·재현 불가·오해 유발·불법·모욕·범위 외 자료를 편집·분류·종료·잠금·숨김·
삭제할 수 있습니다. 참여는 구현·일정·결제·지원·비밀유지 약속을 만들지 않습니다.
