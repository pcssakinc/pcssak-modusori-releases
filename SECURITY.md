# Security Policy

## Private reporting

Do not disclose a suspected vulnerability in a public issue. Use
[GitHub private vulnerability reporting](../../security/advisories/new) for this repository.

Include the affected version, Windows version, reproducible steps, expected and actual behavior,
and the smallest non-sensitive evidence needed to investigate. Do not attach real speech,
transcripts, customer data, credentials, licence keys, updater private keys, or confidential
files.

We will acknowledge a valid report when operationally possible, investigate it, and coordinate
disclosure after a fix or mitigation is available. Early Access does not promise a fixed response
time.

## Scope

Security-relevant areas include updater signature verification, model-download integrity,
external text injection boundaries, audio capture indicators and stopping, local settings and
quota integrity, file parsing, export safety, and installer behavior.

Reports about third-party services should also follow that provider's security policy when the
issue is outside PCssak ModuSori.
