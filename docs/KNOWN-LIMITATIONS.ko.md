# 알려진 제한 — PCssak ModuSori v0.1.1

[English](KNOWN-LIMITATIONS.md) · [릴리스 노트](../RELEASE_NOTES_v0.1.1.md) · [시스템 요구사항](../SYSTEM_REQUIREMENTS.ko.md)

이 문서는 무료 얼리액세스의 경계를 설명합니다. 시험하지 않았거나 없는 기능을 지원 약속으로
오해하지 마십시오.

## 플랫폼과 설치본

- Windows x64 CPU 빌드만 제공하며 AVX2가 필수입니다.
- 현재 지원 중인 Windows 11 Home 또는 Pro x64가 우선 대상이지만 깨끗한 설치 조합은
  `NOT_RUN`입니다.
- Windows x86, Windows on ARM, Windows S 모드, Windows Server, macOS, Linux, Wine은 지원하지
  않으며 설치본도 제공하지 않습니다.
- Windows 10 22H2는 Microsoft 지원이 끝났습니다. 호환성 관찰은 `NOT_RUN`이며 지원
  플랫폼이 아닙니다.
- CUDA·Vulkan을 포함하지 않습니다. CPU 전용 장치에서는 큰 모델이 느릴 수 있습니다.
- 설치본과 앱은 Windows Authenticode로 서명되지 않았습니다. SmartScreen·Smart App
  Control·Defender·다른 보안 제품·조직 정책이 경고하거나 차단할 수 있습니다.
- 현재 사용자 설치·복구·업데이트·제거·WebView2 동작은 깨끗한 Home/Pro 장치 조합을
  마치지 않았습니다.

## 0.1.1 화면·처리 변경

- 메인 화면 배율은 100%·110%·125%·150% 중 선택해 저장할 수 있고 자막 오버레이 글자
  크기는 별도 설정입니다. 다중 모니터·Windows DPI 100~200%·IME·9개 언어 원어민 실제
  장치 조합은 여전히 `NOT_RUN`입니다.
- 녹음이 끝나면 녹음 길이가 고정됩니다. 중지와 변환 상태를 분리하고 처리 경과·실측 인식
  대기량을 표시하며 근거 없는 완료 예상 시간은 표시하지 않습니다.
- 실시간 최종 발화는 CPU 응답성을 위해 1후보 Greedy를 사용하고 파일 일괄 전사는 정확도
  중심 Beam 5를 유지합니다. 어떤 경로도 특정 화자·음원의 정확한 결과를 보장하지 않습니다.
- 중복 중지 요청을 막습니다. 남은 변환 취소는 이미 인식된 문자를 유지하고 해당 세션의 늦은
  결과 전달을 닫지만 실제 마이크·세션·UI·중지·취소 30분 종단 실기는 `NOT_RUN`입니다.

## 음성 인식과 모델

- Whisper 결과는 단어·이름·숫자·억양·문장부호를 누락·대체·중복·잘못 분할할 수 있습니다.
  공인 기록이나 전문 자문이 아닙니다.
- Tiny·Base·Small·Medium·Large-v3 Turbo를 모두 무료 선택할 수 있지만 어떤 모델도 특정
  언어·화자·마이크·소음·CPU에서 정확하거나 빠르다고 보장하지 않습니다.
- 한 개발 PC의 결정론적 30분 live-final 시험은 기능 완료·큐 배출·결과 일관성·추론 처리량
  자동 게이트만 통과했습니다. 146/146 청크를 처리 실패 없이 완료했고 순수 추론은 2.569096배
  실시간·표준 RTF 0.389242였습니다. 메모리는 자동 합격 임계값 없이 첫 전체 청크부터 종료까지
  working set/private +19,968,000/+18,616,320바이트를 수동 관찰했으며 단일 실행은 장시간
  누수를 입증하지도 배제하지도 않습니다. 제품과 같은 36칸 구성을 사용했지만 최대 깊이가 1이라
  포화·역압은 검증하지 않았습니다. 실제 마이크·리샘플링·VAD·앱 세션 이벤트·UI·중지·취소는
  실행하지 않았습니다. 실제 장시간 회의와 소유한 9개 언어 음원의 WER/CER·지연·
  실시간 배수·메모리 벤치마크는 v0.1.1에서도 `NOT_RUN`입니다.
- 모델은 설치본에 없습니다. 처음 사용할 때 Hugging Face 다운로드·저장 공간·고정 크기와
  SHA-256 검증이 필요합니다.
- CPU 전용 릴리스이며 모델 메모리 참고값은 검증된 전체 시스템 RAM 최솟값이 아닙니다.

## 포함하지 않은 기능

- **화자분리 없음:** 전사 구간에 누가 말했는지 표시하지 않습니다. 스테레오·2채널 신호도
  신뢰할 수 있는 다중 화자 이름으로 바꾸지 않습니다.
- **로컬·원격 생성형 LLM 없음:** 회의록은 결정론적 추출식입니다. 문맥을 놓치거나 도움이
  적은 줄을 고를 수 있어 사람이 검토해야 합니다.
- **영어 번역 없음:** 일부 기반 모델이 기술적으로 X→영어 Whisper 작업을 지원하더라도
  무료 얼리액세스 UI가 번역을 차단합니다.
- 클라우드 계정·팀 관리·협업 공간·클라우드 동기화·온라인 전사·유료 플랜·결제·유료
  라이선스를 제공하지 않습니다.

## 음성 타이핑

- 현지 날짜 기준 하루 15회입니다.
- 검증된 Windows 입력 대상에만 자동 입력합니다. 비밀번호 필드·유효하지 않거나 바뀐 대상·
  권한 수준 불일치·수정키 잔류·접근할 수 없는 초점은 추측하지 않고 거부합니다.
- 관리자 권한 앱·브라우저·Office·한국어/일본어 IME·다중 모니터·최소화 창·빠른 시작/중지
  조합은 실제 장치 조합에서 `NOT_RUN`입니다.
- 음성 명령은 범용 원격 제어나 자동화 인터페이스가 아닙니다.

## 실시간 자막과 오디오 장치

- 한 세션은 마이크 또는 Windows 시스템 오디오 중 하나만 사용합니다.
- 무료 얼리액세스는 세션 5분 뒤 중지하며 사용자가 새 세션을 시작할 수 있습니다.
- 루프백 캡처는 호환되는 활성 Windows 출력 장치가 필요합니다. 보호 스트림·독점 모드·
  Bluetooth 프로필·도크·가상 장치·절전 복귀·장치 분리 동작은 달라질 수 있습니다.
- 자막 기록에는 상한이 있습니다. 중요한 문자는 검토·내보내야 하며 영구 법률 기록이 아닙니다.
- 녹음·시스템 오디오 법률, 참여자 동의, 직장 정책, 콘텐츠 권리는 사용자가 확인해야 합니다.

## 파일 전사와 내보내기

- 파일당 최대 15분입니다.
- WAV, MP3, M4A, MP4, FLAC, OGG, OGA, AAC, MKA, MKV를 받지만 알려진 확장자만으로 모든
  코덱·손상 컨테이너·암호화 스트림·특수 메타데이터 지원을 보장하지 않습니다.
- SRT·WebVTT·Markdown·TXT를 내보냅니다. 자막 타임라인 편집기·영상 번인·FFmpeg 연동·화자
  트랙은 없습니다.
- 저장 취소·권한·디스크 부족·파일 잠금·경로 정책·외부 변경 때문에 내보내기가 실패할 수
  있습니다. 최종 파일을 대상 프로그램에서 다시 확인하십시오.

## 회의록

- 현지 날짜 기준 하루 3회입니다.
- 결정론적 규칙으로 원문 줄을 선택·정리합니다. 생성형이 아니며 모든 결정·담당자·기한·부정·
  농담·전문 용어를 이해하지 못합니다.
- 먼저 원음과 전사를 대조하십시오. 전사 오류가 회의록에 보존되거나 강조될 수 있습니다.
- 화자 귀속·클라우드 모델·Ollama·llama.cpp·다른 로컬 LLM은 포함하지 않습니다.

## 복구·개인정보·자료

- 비정상 종료 복구는 제한된 문자와 시간 정보만 가지며 원음·원본 경로·파일명은 저장하지
  않습니다. 전체 프로젝트 백업이 아닙니다.
- 현재 Windows 사용자 DPAPI를 사용하고 최대 7일 뒤 만료하며 손상·만료·알 수 없는 형식·
  정책 초과 파일은 전체 거부합니다. 정상 종료나 사용자 폐기 시 초안을 지웁니다.
- DPAPI는 관리자·같은 Windows 사용자 권한 악성코드·잠금 해제 장치·메모리 검사·백업 도구·
  클라우드 동기화를 막지 않습니다.
- 앱에는 텔레메트리·자동 오류 업로드가 없습니다. 모델·업데이트·WebView2·외부 링크·이메일·
  공개 GitHub 요청은 해당 제공자에게 일반 네트워크 메타데이터를 보일 수 있습니다.
- 공개 이슈 첨부는 로컬·비공개가 아닙니다. 실제 음성·전사·경로·인증정보·고객 자료·회사
  비밀을 올리지 마십시오.

## 업데이트

- 시작 시 자동 확인은 한 번 시도하며 수동 확인은 별도 시도입니다. 네트워크·GitHub 실패를
  업데이트가 없다는 증거로 해석하면 안 됩니다.
- 다운로드·설치는 사용자가 승인합니다. 진행 중 작업·미저장 결과가 있으면 차단할 수 있습니다.
- Tauri 업데이트 서명은 업데이트 바이트를 보호하지만 Authenticode 게시자 신원이 아닙니다.
- 별도 설치 PC의 v0.1.0→v0.1.1 성공·재시작 경쟁·롤백·재생·변조 업데이트 실기는
  v0.1.1에서 `NOT_RUN`입니다.
