# PCssak ModuSori 설치 및 업데이트

[English](INSTALLATION.md) · [시스템 요구사항](../SYSTEM_REQUIREMENTS.ko.md) · [알려진 제한](KNOWN-LIMITATIONS.ko.md)

이 안내는 Windows x64용 v0.1.2 무료 얼리액세스에 적용됩니다.
[공식 고정 v0.1.2 릴리스](https://github.com/pcssakinc/pcssak-modusori-releases/releases/tag/v0.1.2)
또는 [PCSSAK 공식 제품 페이지](https://pcssak.co.kr/modusori)에서만 내려받으십시오.

## 설치 전 확인

1. 현재 Microsoft 지원을 받는 Windows 11 Home 또는 Pro x64인지, CPU가 AVX2를 지원하는지
   확인합니다. 다른 플랫폼은 지원 경계 밖입니다.
2. 중요한 원음·전사·회의록·내보낸 파일을 백업합니다.
3. 고정 `v0.1.2` 릴리스에서 Windows x64 NSIS 설치본과 `SHA256SUMS.txt`를 받습니다. GitHub가
   자동 생성한 소스 압축 파일은 설치본이 아닙니다.
4. PowerShell에서 설치본 해시를 계산합니다.

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath (Read-Host '다운로드한 설치 파일의 전체 경로')
   ```

5. 64자리 전체를 같은 릴리스의 `SHA256SUMS.txt` 설치본 항목과 비교하고 하나라도 다르면
   중단합니다. 최종 파일명·해시·크기는 이 안내가 아니라 실제 릴리스 페이지를 기준으로 합니다.
6. Microsoft Defender·SmartScreen·Smart App Control·조직 정책을 켜 둡니다.

v0.1.2 설치본은 Windows Authenticode로 서명되지 않았습니다. SHA-256이 같아도 Windows에
**알 수 없는 게시자** 또는 평판 경고가 나타날 수 있습니다. 해시는 공개 자산과 바이트가
같음을 확인할 뿐 게시자 신원이나 악성코드 부재 보증이 아닙니다. 보안 정책이 차단하면
중단하고 승인된 시험 PC를 사용하거나 서명된 후속 버전을 기다리십시오. 보안 기능을 끄지
마십시오.

## 최초 설치

NSIS 설치기는 현재 Windows 사용자 범위로 구성되며 영어·한국어·일본어·독일어·프랑스어·
국제 스페인어·브라질 포르투갈어·튀르키예어·러시아어를 제공합니다. 언어를 선택하고 동봉
EULA를 읽은 뒤 동의할 때만 계속하십시오. 현재 사용자 설치가 의도한 구성이지만 깨끗한
장치의 권한·조직 정책 동작은 v0.1.2에서 `NOT_RUN`입니다.

화면에는 Microsoft Edge WebView2 Runtime이 필요합니다. 없으면 설치 과정이 Microsoft의
WebView2 배포 서비스에 연결할 수 있습니다. 프록시·오프라인·조직 정책·보안 제품 조합은
실제 장치 검증을 마치지 않았습니다.

앱을 처음 실행하면 EULA와 개인정보 처리방침 전문을 다시 표시합니다. 두 확인란은 기본
해제되며 사용자가 모두 직접 선택해야 앱을 사용할 수 있습니다. 녹음·시스템 오디오 작업은
앱 안의 안전 고지와 매 세션 확인도 필요합니다.

## Whisper 모델 설치

모델 가중치는 설치본에 포함하지 않습니다. 모델 관리자에서 Tiny·Base·Small·Medium·
Large-v3 Turbo 중 하나를 고르십시오. 앱은 고정
[`ggerganov/whisper.cpp` Hugging Face 저장소](https://huggingface.co/ggerganov/whisper.cpp)에서
직접 내려받고 부분 다운로드 이어받기를 지원하며 정확한 바이트 길이와 고정 SHA-256이 모두
맞아야 모델을 사용합니다.

자원이 제한된 PC에서는 작은 모델부터 사용하십시오. 모델 크기·메모리 참고값은
[시스템 요구사항](../SYSTEM_REQUIREMENTS.ko.md)을 확인하십시오. 검증하지 않은 모델을 앱
데이터 폴더에 복사하거나 다른 다운로드 주소로 바꾸지 마십시오.

## 업데이트

- 릴리스 빌드는 시작 뒤 자동 확인을 최대 한 번 시도하고 사용자가 수동 확인도 시작할 수 있습니다.
- 앱은 다운로드 전에 후보 버전과 변경 내용을 보여 줍니다. 다운로드·설치에는 사용자 승인이
  필요하며 조용히 자동 설치하지 않습니다.
- 녹음·전사·미저장 결과·모델 작업·다른 보호 작업이 있으면 설치를 보류하거나 거부합니다.
- 업데이터는 필수 Tauri 설치본 서명, 별도 서명된 배포 매니페스트, 예상 버전·URL·SHA-256을
  모두 확인한 뒤 적용합니다.
- Tauri 서명은 Windows Authenticode가 아닙니다. 업데이트 바이트를 보호하지만 미서명
  설치본을 알려진 Windows 게시자로 바꾸지 않습니다.
- 설치된 버전보다 높은 승인 버전만 업데이트 후보가 될 수 있습니다. 별도 PC에 설치된
  v0.1.1→v0.1.2 정상·변조 업데이트 실기는 계속 `NOT_RUN`입니다.

업데이트 확인이 실패하면 모델이 설치된 기존 버전을 계속 사용하거나 공식 고정 릴리스를
확인하십시오. 서명 오류를 우회하거나 메타데이터를 바꾸거나 미러·재패키지 파일을 설치하지
마십시오. 별도 PC의 정상·변조 업데이트 실기는 v0.1.2에서 `NOT_RUN`입니다.

## 복구 설치·재설치

공식 고정 태그에서 다시 받고 SHA-256 비교를 반복하십시오. 설치본을 실행하기 전에
ModuSori를 정상 종료하고 중요한 결과를 먼저 내보내거나 백업하십시오. 모든 설정·복구 상태·
모델·대기 결과가 복구 설치·재설치에서 보존되는지 깨끗한 PC 조합을 마치지 않았으므로
재설치를 백업 대신 사용하면 안 됩니다.

## 제거와 로컬 데이터

Windows **설정 → 앱 → 설치된 앱**에서 PCssak ModuSori를 제거합니다. 앱을 닫고 중요한
결과를 먼저 내보내십시오. 실행 파일을 제거해도 모든 모델·설정·복구 파일·내보낸 결과·부분
다운로드·브라우저 다운로드·백업·클라우드 동기화본이 삭제된다고 약속하지 않습니다.

제거와 백업 뒤 남은 로컬 앱 데이터까지 의도적으로 지우려면 아래 정확한 사용자별 위치만
검토하십시오.

- `%APPDATA%\com.pcssak.modusori`
- `%LOCALAPPDATA%\com.pcssak.modusori`

상위 폴더·비슷한 이름의 폴더·내보낸 파일 위치를 지우지 마십시오. Windows 휴지통·백업·
보안 프로그램·클라우드 동기화의 보유는 별도로 관리됩니다.

안전한 문제 해결은 [지원 안내](../SUPPORT.md), 취약점 비공개 제보는
[보안 정책](../SECURITY.md)을 확인하십시오.
