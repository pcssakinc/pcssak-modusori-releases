# 품질과 안전 — PCssak ModuSori

[English](QUALITY-AND-SAFETY.md) · [알려진 제한](KNOWN-LIMITATIONS.ko.md) · [보안 정책](../SECURITY.md)

이 문서는 v0.1.2 무료 얼리액세스의 엔지니어링 경계와 필요한 검증 근거를 설명합니다. 앱에
오류가 없거나 모든 언어에서 정확하거나 모든 국가에서 법적으로 적합하거나 보안 제품의
승인을 받았다는 인증서가 아닙니다.

## 로컬·사용자 통제 흐름

1. 사용자가 마이크·Windows 시스템 오디오·지원 미디어 파일을 선택합니다.
2. 앱이 해당 법률·녹음 안전 확인을 요구합니다.
3. 로컬에 설치되고 해시를 검증한 Whisper 모델이 PC에서 문자를 만듭니다.
4. 사용자가 전사·자막·추출식 회의록을 검토합니다.
5. 명시적 저장·복사 동작을 한 뒤에만 사용자가 선택한 대상으로 결과를 보냅니다.

앱에는 PCSSAK 계정·텔레메트리·광고·사용 분석·추적 SDK·자동 오류 업로드가 없습니다.
음성·문자를 PCSSAK 처리 서버로 보내지 않습니다. 모델·업데이트·WebView2·사용자가 연 링크·
이메일·GitHub 연결은 각 외부 제공자의 일반 네트워크 메타데이터 처리 대상입니다. 공개
제보는 로컬·비공개 처리가 아닙니다.

## 녹음과 동의 안전

- 최초 사용 시 EULA와 개인정보 처리방침 전문을 능동적으로 모두 확인해야 합니다. 문서
  버전·해시가 바뀌면 다시 확인합니다.
- 최초 녹음 사용은 긴 안전 고지를 표시하며 각 캡처 세션에도 짧은 확인이 필요합니다.
- UI와 자막 오버레이는 활성 캡처를 표시하고 중지 경로를 제공합니다.
- 마이크·시스템 오디오는 다른 사람·알림·저작권 콘텐츠·기밀 대화·규제 정보를 포착할 수
  있습니다. 사용자가 필요한 모든 권한을 얻고 동의 철회 시 중지해야 합니다.
- 이 기능은 알림·확인 장치이며 신원·나이·권한·참여자 동의·직장 정책·법률 적합성을
  검증하지 않습니다.

## 음성 타이핑 대상 안전

전역 단축키 음성 타이핑은 백엔드의 불투명 대상 토큰만 보관합니다. 자동 입력 직전에 대상
창·프로세스·초점·비밀번호 필드·권한 수준·입력 데스크톱·수정키 상태를 다시 확인합니다.
검증한 대상이 없거나 바뀌면 자동 입력을 거부하고 ModuSori로 돌아옵니다. 이는 오입력·노출
위험을 줄이지만 모든 외부 앱·IME 호환성을 만들지는 않습니다.

## 결과와 종료 안전

- 전사·추출식 회의록은 틀릴 수 있습니다. 중요한 결과는 원음과 대조하고 사람이 검토해야 합니다.
- 지원 내보내기 형식은 백엔드가 만들고 네이티브 대화상자·고정 확장자·원자 교체 경계로 저장합니다.
- 녹음·전사·모델 변경·내보내기·요약·업데이트 설치는 백엔드 작업 게이트로 경쟁을 줄입니다.
- 녹음·중지·변환은 서로 다른 상태로 표시합니다. 캡처가 끝나면 녹음 길이를 고정하고 변환
  경과·실측 대기량을 표시하며 근거 없는 완료 예상 시간은 만들지 않습니다.
- 중복 중지 요청을 막습니다. 별도 남은 변환 취소는 이미 인식된 문자를 유지하고 해당 세션의
  늦은 출력 전달을 닫으며 대기 추론에 협력 취소를 요청합니다.
- 프런트 미저장 결과와 백엔드 미확인 출력은 종료·업데이트 보호 대상입니다. 결과 폐기는
  사용자가 명시적으로 선택해야 합니다.
- 중복 실행 처리는 두 번째 오디오 엔진을 시작하지 않고 기존 앱으로 돌아옵니다.

이 장치는 흔한 손실·동시성 위험을 줄이지만 별도 백업을 대신하지 않습니다.

## 화면과 접근성 안전

- 앱 셸은 메인 WebView와 일치하는 유한한 너비·높이 경계를 가집니다.
- 화면 배율은 CSS `zoom`이 아니라 Tauri/WebView2 네이티브 페이지 확대를 사용하여 레이아웃
  뷰포트·반응형 기준·뷰포트 단위 대화상자를 하나의 배율 경계에 둡니다.
- 네 기능 탭은 하나의 유한한 공통 세로 스크롤 영역 안에 있습니다. 이 영역은 키보드 초점을
  받고 포커스 표시를 보이며 9개 UI 언어 접근성 이름을 가집니다.
- 자동 뷰포트·배율·키보드·대화상자·렌더 화면 계약은 회귀 근거일 뿐입니다. 실제 WebView2의
  OS DPI 100–200%·다중 모니터·창 크기·터치패드·터치·IME·보조 기술 실기는 `NOT_RUN`입니다.

## 비정상 종료 복구

복구는 원음·원본 경로·파일명 없이 상한이 있는 편집 문자와 시간 정보만 저장합니다. 전체
파일을 현재 Windows 사용자 DPAPI로 보호하고 revision을 검사하며 정책 상한을 적용하고 최대
7일 뒤 만료합니다. 손상·만료·알 수 없는 형식·상한 초과 자료는 전체 거부합니다. 정상 종료·
명시적 폐기 시 초안을 지웁니다.

복구는 전체 프로젝트 저장이 아니며 DPAPI는 관리자·같은 사용자 권한 악성코드·잠금 해제
장치·메모리 검사·백업·동기화 도구를 막지 않습니다.

## 모델·업데이트 공급망

- 모델은 선택형이며 사용자가 요청한 뒤에만 고정 `ggerganov/whisper.cpp` Hugging Face
  출처에서 받습니다.
- 각 모델은 고정 파일명·정확한 크기·SHA-256을 가집니다. 부분 다운로드를 이어받지만 최종
  불일치는 설치하지 않고 거부합니다.
- 업데이트는 이 공개 릴리스 저장소를 사용합니다. 설치는 사용자 승인이 필요하며 보호 작업·
  미저장 출력이 있으면 차단합니다.
- 앱은 Tauri 설치본 서명·별도 서명된 배포 매니페스트·버전·정규 URL·릴리스 노트 해시·
  설치본 SHA-256을 확인합니다. 과거·교체 후보의 재생을 거부합니다.
- 고정 릴리스는 해시·소스/빌드/서명 출처·법률 문서·정확한 제3자 고지·SPDX SBOM을
  공개하며 릴리스 절차의 정확한 자산 허용목록만 게시합니다.

Tauri 서명은 Windows Authenticode 게시자 신원이 아닙니다. v0.1.2 설치본은 Windows 기준
미서명 상태이므로 경고·차단될 수 있습니다.

## 자동 검증 계층

공개 전 정확한 후보는 다음 성공 결과를 기록해야 합니다.

- 프런트 계약 시험과 실제 DOM·키보드·초점·접근성·뷰포트·배율 상호작용 시험
- TypeScript 검사와 Vite 운영 빌드
- Rust 단위·통합 시험, 포맷, 모든 경고를 오류로 처리한 Clippy, 릴리스 빌드
- 중복 실행·종료·업데이트·모델·동의·복구·사용량·내보내기·동시성 계약
- 9개 UI 언어 키·자리표시자·지역 숫자·오류 목록 일치
- 의존성 권고·라이선스·출처 정책·npm 감사·비밀정보·워크플로 정적 검사
- 법률 얼리액세스 게이트와 동봉 문서 일치
- NSIS 아키텍처/설정·업데이트 서명·서명 매니페스트·SBOM·정확한 자산·SHA-256 검증

고정 릴리스 자산·릴리스 노트·빌드 출처가 공개 후보의 근거입니다. 소스 시험 통과는 깨끗한
Windows 설치·드라이버 호환·음성 정확도·장시간 동작·원어민 번역 품질·보안 제품 평판·법률
적합성을 증명하지 않습니다.

한 개발 PC의 결정론적 30분 live-final 시험은 기능 완료·큐 배출·결과 일관성·추론 처리량
자동 게이트만 통과했습니다. 146/146 청크를 처리 실패 없이 완료했고 순수 추론은 2.569096배
실시간·표준 RTF 0.389242였습니다. 메모리에는 자동 합격 임계값이 없으며 첫 전체 청크부터
종료까지 working set/private +19,968,000/+18,616,320바이트를 수동 관찰했습니다. 단일 실행은
장시간 누수를 입증하지도 배제하지도 않습니다. 제품과 같은 36칸 큐 구성을 사용했지만 최대 관찰
깊이가 1이므로 포화·역압은 검증하지 않았습니다. 실제 마이크·리샘플링·VAD·앱 세션 이벤트·
UI·중지·취소를 30분 동안 검증한 것은 아닙니다.

## 사람·실제 장치 검증 계층

v0.1.2에서 깨끗한 Windows 11 Home/Pro, Windows 10 관찰, Intel/AMD·오디오 장치 조합,
실제 마이크·VAD·세션·UI·중지·취소 30분 종단 실기, 실제 장시간 회의·소유한 9개 언어
벤치마크, 9개 언어 원어민 검수, WebView2 OS DPI 100–200%·다중 모니터·창 크기·터치패드·
터치·IME·보조 기술, 보안 제품, 별도 PC v0.1.1→v0.1.2
업데이트, 출시 지역 법률 검토는 모두 `NOT_RUN`입니다. 정확한 표는
[알려진 제한](KNOWN-LIMITATIONS.ko.md)과 [릴리스 노트](../RELEASE_NOTES_v0.1.2.md)에 있습니다.

무료 얼리액세스는 공개 뒤 실제 사용자 근거를 모으는 단계입니다. 사용자 제보를 자동 통과·
성능 결과로 처리하지 않으며 재현 방법·비민감 샘플·장치 정보·기대 결과·실제 결과가 필요합니다.

## 안전한 의견 전달

공개 이슈 양식에는 비민감 재현 정보만 적으십시오. 원본 음성·개인 전사·고객 자료·인증정보·
개인 경로·회사 비밀을 첨부하지 마십시오. 악용 가능한 취약점은
[비공개 보안 제보](../SECURITY.md)를 사용하십시오.
