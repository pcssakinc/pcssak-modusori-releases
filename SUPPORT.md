# Support

This repository does not yet contain a public installer. Until the first approved Early Access
release, issues should concern the public release plan or clearly identified pre-release testing.

For a bug report, include:

- exact PCssak ModuSori version;
- Windows edition, version, architecture, and update level;
- CPU and memory amount, and selected model;
- input source or media container/codec without attaching private content;
- reproducible steps, expected behavior, and actual behavior;
- whether the issue persists after a normal application restart.

Remove user names, full paths, organisation names, audio, transcripts, credentials, licence keys,
and confidential data. Create a small synthetic sample when media is required for reproduction.

Use [private security reporting](SECURITY.md) instead of a public issue for vulnerabilities.
